
# wtfMusic

wtfMusic is a web music application developed for fun. It leverages various JavaScript libraries and frameworks to provide an engaging user experience.

## Features
- Stream and play music
- User authentication
- Music library management
- Real-time updates with Socket.io

## Installation

To install the necessary dependencies, run the following command:

```bash
npm install
```

## Usage

To start the application, use the following command:

```bash
npm start
```
